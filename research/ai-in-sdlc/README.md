# research/ai-in-sdlc/

General research on AI use across the software development lifecycle —
SDLC fundamentals, AI-assisted coding, AI-assisted testing, and tool/model
benchmarking all land here. This folder is organized **by person, not by
topic**: each team member keeps one running findings file, using
[TEMPLATE.md](TEMPLATE.md) as the capture format for each source they add
to it. It also holds `synthesis.md`, the cross-person rollup.

## What belongs here

- `TEMPLATE.md` — the capture format; copy its fields for each new source
- One file per person, named `firstname.md` (e.g. `sajad.md`,
  `thomas.md`, `ujjawal.md`, `william.md`)
- Each entry in that file is a source capture using
  [TEMPLATE.md](TEMPLATE.md) — source with link, date, who reviewed it,
  key findings, which lifecycle phase it relates to, and why it matters
  for the white paper
- Any topic is fair game here: SDLC theory, AI-assisted coding, AI-assisted
  testing, tool benchmarks, governance research, etc. — the organizing
  principle is "who found this," not "what stage it's about"
- `synthesis.md` — the rollup that pulls findings across everyone's
  captures into conclusions that feed the white paper

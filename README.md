# GROUP-19-NBN-SDLC

## What this is

A capstone project for NBN Co, delivering a technical white paper that
defines how software developers should work when continuously using LLMs
throughout the software development lifecycle (SDLC). The white paper is
the main deliverable. It is backed by research, design artifacts (a
lifecycle map and its validation), and a demonstration project built in a
later sprint to show the methodology in practice.

This is a documentation project, not a code project — see
[CONTRIBUTING.md](CONTRIBUTING.md) before adding anything.
